# 🧩 Data ETL Pipeline

A simple, production-style **ETL (Extract–Transform–Load) pipeline** built using Python and Pandas, with **Jenkins CI/CD automation** for scheduled and repeatable runs.

---

## 📘 Overview

This project demonstrates the fundamentals of a real-world ETL workflow:

- Extract data from CSV/JSON files  
- Transform and clean the data using Pandas  
- Load the processed data into a structured format  
- Automate the workflow using Jenkins  

It is designed as a beginner-friendly data engineering project that showcases practical understanding of ETL, Python scripting, automation, and DevOps integration.

---

## 🚀 Features

- **🗃️ Extract** data from CSV and JSON files  
- **🧹 Transform** using Pandas (cleaning, formatting, type conversion)  
- **📥 Load** cleaned data into a target file or database  
- **⚙️ Jenkins Integration** for automated execution  
- **🧾 Logging** for debugging and tracking pipeline runs  
- **📂 Modular Code Structure** for easy extension
